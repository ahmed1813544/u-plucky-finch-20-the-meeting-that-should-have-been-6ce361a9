## What it does

`main.py` (Python 3, standard library only) writes exactly one line — a single joke about a meeting that should have been an email — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The line is 164 characters, well inside the 200-character gate, and the output is identical on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
